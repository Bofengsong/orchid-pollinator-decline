# R packages

The scripts use the following packages:

- `cowplot`
- `dplyr`
- `ggplot2`
- `janitor`
- `metafor`
- `patchwork`
- `purrr`
- `readr`
- `readxl`
- `rnaturalearth`
- `scales`
- `sf`
- `stringr`
- `terra`
- `tibble`
- `tidyr`

Base R package `grid` is also used. Package versions should be captured in an
archival release before publication.
