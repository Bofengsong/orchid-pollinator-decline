# Spatial inputs

The processed inputs in `data/Supporting_data.rds` are sufficient for the supplied analysis and plotting scripts. They include the orchid distribution and richness layers, environmental pressure layers, map boundaries and plotting assets used in the manuscript. Source descriptions and citations follow the manuscript Methods: WCVP/TDWG, GBIF, PESTCHEMGRIDS, TerraClimate and Global Human Modification.

Spatial prioritisation uses a 2° grid and 300 publication-level bootstrap iterations. Scripts retain the stated model and classification rules. The priority classes describe the integrated framework, not directly observed pollinator losses at unsampled locations.
