# Data definitions

`Final_data.csv` has one row per Evidence record. `evidence_record_id` identifies the row; `reference_no` links records from the same publication. Species, location, comparison period and extracted notes remain attached to their records.

`meta_included = 1` identifies the 251 records used in the primary meta-analysis. `meta_effect_id` is the stable effect identifier. Fields prefixed `meta_` contain the corresponding Meta values; other Evidence records retain their source information without entering the primary model.

For ordinary ratio comparisons, `decline_value = RR - 1` and `yi = ln(RR)`. Response definitions, comparison windows and corrections are recorded with the data. `vi` is either a source-derived variance or the documented sample-size-based working proxy; `1/N` is not a universally estimated sampling variance. `sample_size` retains the source-specific unit explained in the notes.

`Supporting_data.rds` contains processed map layers, time definitions and supplementary inputs. `Results.rds` contains fitted models, model membership, diagnostics and spatial results generated by `Analysis.R`. `Results.csv` provides model summaries.

The Excel workbook contains the same current table on one `Data` worksheet; long notes are retained in full in the CSV.
